# 📜 Código de Conducta

## Nuestro compromiso

En Cerebro Zero nos comprometemos a mantener un entorno abierto, inclusivo y respetuoso para todos.

## Estándares

- Usar un lenguaje inclusivo
- Respetar diferentes puntos de vista
- Aceptar críticas constructivas
- Mostrar empatía

## Comportamiento inaceptable

- Lenguaje ofensivo o discriminatorio
- Acoso en cualquier forma
- Publicar información privada

## Alcance

Este código de conducta aplica en todos los espacios del proyecto (issues, pull requests, comentarios).

## Contacto

Si tienes problemas, contacta al mantenedor del proyecto.
