## Reportar vulnerabilidades

Si encuentras una vulnerabilidad de seguridad:

1. **No abras un issue público**
2. Envía un correo a: axiomsystemsechepares@gmail.com
3. Describe el problema con detalle
4. Espera respuesta antes de hacer público

## Prácticas de seguridad

- No ejecutes código de fuentes no confiables
- Usa el proyecto en entornos controlados
- Revisa siempre el código antes de ejecutarlo

---

**La seguridad es responsabilidad de todos.** 🛡️
